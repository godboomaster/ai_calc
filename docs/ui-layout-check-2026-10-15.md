# Проверка единой компоновки

Ветка: `codex/ui-layout-consistency`, база: `00147ec`.

## Автоматическая проверка

- Первый проход: debug APK, 358 unit tests без ошибок, lintDebug — успешно.
- Финальный проход после исправления полноэкранной схемы: `assembleRelease lintDebug` — успешно (4 мин 5 с).
- Изолированная сборка с `-PconnectionsDeviceCheck`: успешно.
- Прямой переход к подключениям и доступность кнопки сохранения при открытой клавиатуре: успешно на API 35.
- Два существующих теста редактора потребовали обновления помощника: закреплённая кнопка больше не имеет прокручиваемого родителя. После исправления повторный прогон редактора и чтения решения: 5 тестов успешно, включая повороты, черновик, переход к подключениям и клавиатуру.
- Подготовка офлайн-примеров `LayoutFixturesDeviceTest`: успешно, 1 тест.
- Независимый просмотр diff: исправлен переход, показывавший только заголовок раздела; длинные ошибки соединения вынесены из неподвижной панели.

## Визуальный обход

Эмулятор API 35 запущен и открыт. Основной обход выполнен в изолированном пакете с синтетическими данными без API-запросов.

Проверены:

- Калькулятор, помощник, меню подключений, ввод с системной клавиатурой.
- Настройки, раскрытие промпта, прямой переход к подключениям, редактор подключения и меню формата. Сохранение остаётся доступным с клавиатурой.
- Оформление, список образцов с длинным названием, редактор образца и его поля с клавиатурой.
- Поиск, результаты из библиотеки и истории, раздел библиотеки, просмотр и редактор задачи.
- Файлы, добавление материала, выбор фрагментов, проверка разбора, просмотр исходных фрагментов и переход между ними. Исправлены отступы карточки выбора и нижней панели файлов.
- История, краткий ответ, полное решение, сворачивание блоков, таблица, график, переход к редактированию условия.
- Шаг с длинным названием, закреплённые стрелки, список шагов, отдельный этап ответа.
- Полноэкранная схема: заменён правый крестик на общий экран чтения со стрелкой слева; двойное касание увеличивает схему, изображение не перекрывает шапку.
- Камера при отклонённом доступе: пояснение видно, возврат в калькулятор работает. Системный запрос закрыл пользователь, повторно доступ не запрашивался.

Ограничения: изображение с камеры не проверялось из-за отказа в доступе. Отдельный полноэкранный растровый просмотр, все варианты пустых состояний и подтверждений, тёмная тема и увеличенный системный шрифт не прошли отдельный полный визуальный прогон. Это обход основных экранов и затронутых сценариев, а не всех комбинаций состояний.

## Сохранность данных

Основной пакет не очищался и не удалялся. Попытка установить debug APK поверх основной версии отклонена Android из-за другой подписи, без изменения данных. Обновление основной версии выполняется через `adb install -r` с прежней локальной подписью. Пользовательский API-ключ не извлекался, не раскрывался в интерфейсе и не выводился в журнал.

Синтетические данные создаются только в `com.smartcalc.app.connectionscheck`; перед выполнением тест проверяет имя пакета. API-запросы при подготовке не выполняются.

Финальная локальная release-сборка установлена поверх основного «Калькулятора» с исходным сертификатом. Установка завершилась `Success`, запуск и экран калькулятора визуально проверены. Computer Use освобождён сбросом сессии, эмулятор оставлен открытым.

## Дополнение: прокрутка клавиш

По замечанию пользователя воспроизведено растягивание сетки при прокрутке на экране, где все клавиши помещаются: верхний ряд частично обрезался. Причина — безусловно включённый `verticalScroll`. Теперь он включается только при превышении высотой клавиш доступной области. На API 35 после обновления проверена прокрутка в обе стороны: сетка остаётся неподвижной. `assembleRelease` прошёл, основное приложение обновлено с сохранением данных. Сценарий очень низкого экрана в этом дополнительном проходе отдельно не проверялся.
