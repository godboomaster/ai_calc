# Проверка импорта через окно эмулятора — 2026-10-12

Проверка выполнена через плагин Computer Use в одном окне
`Android Emulator - SmartCalc_API35:5554` (Android 15 / API 35).
Все действия интерфейса — мышь, прокрутка и ввод текста через Computer Use.
Другие окна Windows не активировались. Команды использованы для запуска эмулятора,
сборки и установки изолированного APK; adb input, UI dump и adb screenshots
в этой проверке не использовались.

Пакет: `com.smartcalc.app.importcheck`. Основное приложение и пользовательская
фотография «Вариант 3.jpg» не затрагивались. Использована синтетическая фикстура
`smartcalc-i01.txt`; экран разбора показывал **0/10 запросов**.

## Проверенный путь

1. Системный выбор TXT из Downloads; повтор исходника распознан, показан уже
   обработанный диапазон 1–14. Диапазон изменён на 1–7: выбрано 7, осталось 7.
2. Получен один черновик с условием, авторским решением и отдельным ответом.
   Ответ отредактирован с меткой `GUI-check`.
3. Открыта ссылка на фрагмент 3 оригинала. После возврата правка сохранилась.
4. Развёрнуто сравнение с прежним примером версии 1: прежний ответ не изменился.
5. Выполнены разделение и объединение. После исправления один выбранный черновик
   не разрешает объединение; два разрешают; после объединения счётчик выбранных
   равен нулю и удалённые идентификаторы не попадают в действия.
6. При открытой экранной клавиатуре поле имени раздела доступно над ней.
   Введено `GUI-check`, подтверждены ручная проверка границ и сравнение с прежней
   задачей. Опубликована одна задача; повторный разбор отмечен как добавленный.
7. Библиотека содержит отдельный раздел `GUI-check` с одной задачей и прежний
   `smartcalc-i01` с двумя задачами. Поиск `GUI` показывает один новый результат
   с пометкой «Исходный пример: Не проверено».
8. Переключатель исходника «Использовать в поиске» выключен: результат исчез,
   показана подсказка о недоступных задачах. После включения результат вернулся.
   Исходник оставлен включённым, окно — на найденной задаче без клавиатуры.

## Найденные и исправленные ошибки

- После разделения/объединения выбранные идентификаторы удалённых черновиков
  оставались в UI. Это разрешало объединение одного видимого черновика и давало
  ошибку; счётчик публикации также завышался. Действия и счётчик теперь используют
  только существующие, неопубликованные и не исключённые черновики; сохранённый
  выбор очищается при изменении списка. Добавлены два регрессионных JVM-теста.
- Клавиатура закрывала нижнее поле имени раздела, которое нельзя было показать
  прокруткой. Добавлен `imePadding()` на экраны подготовки и проверки импорта;
  доступность поля на экране проверки повторно подтверждена через окно эмулятора.
