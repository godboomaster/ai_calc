## Что проверено на устройстве

Android-тесты сохраняют исходные байты TXT UTF-8/1251, PDF, DOCX, JPEG и PNG,
повторяют загрузку по SHA256, извлекают весь диапазон и повторно открывают **каждую** ссылку.
Проверяется ограничение растров 4 мегапикселями, шестая страница PDF, EXIF,
нормализация рисунка DOCX в JPEG и замечание для неподдерживаемого рисунка.
Защищённый PDF и старый DOC отклоняются с сохранением доступного оригинала PDF.

Полный локальный путь I01: две задачи → отдельные ответы → публикация UNVERIFIED →
повторное чтение stores → отключение источника исключает результаты поиска → удаление
оригинала сохраняет задачи → повтор публикации подтверждается прежней квитанцией.
В этом тесте транспорт запрещает сеть; фактическое число POST — **0**.

Вручную через UI: системный выбор синтетического TXT из Download → диапазон 1–14 →
2 черновика / 0 POST → открытие ссылки на фрагмент 3 → публикация двух задач →
force-stop/restart → один раздел, две задачи, одна квитанция → два результата поиска с
отдельными ответами и пометкой «Не проверено». Смена конфигурации шрифта сохранила
экран разбора и поля. Поворот не является проверкой recreation: Activity закреплена в portrait.
Повторный разбор показал обработанный диапазон 1–14 и прежний пример с его условием, решением,
ответом и версией. Кнопка добавления была disabled до подтверждения сравнения и enabled после;
повторная публикация не выполнялась, число опубликованных задач осталось **2**.

автоматически; сохранённый пригодный ответ разбирается локально без ключей.

## Итоговое ревью

Независимое Astra-ревью диапазона `main..590934c`: 5 Important, 0 Critical, 0 Minor.
Все пять замечаний воспроизведены падающими тестами и исправлены в `127d7f2`:

1. Ручной повтор после HTTP 429/500 или malformed JSON освобождает неудачный checkpoint.
   Дополнительно проверен HTTP 422, сохранённый на границе лимита перед паузой.
2. Image-only блок DOCX сохраняет ссылки, изображения нужного поля и предупреждения.
3. Carry сохраняет предыдущие изображения/предупреждения; они входят в лимит пакета.
4. Не помещающееся продолжение становится полным редактируемым черновиком с замечанием.
5. Повтор непубликованного намерения после исправления раздела получает актуальный snapshot;
   прежняя квитанция по-прежнему предотвращает повторную публикацию.

Финальная проверка спецификации также добавила сравнение нового разбора с прежними примерами
по ссылкам, отображение обработанных диапазонов и явное подтверждение добавления как новых задач.
Автоматической замены или объединения с локальными исправлениями нет.

## Решения при выполнении

| Решение | Основание и цена ошибки |
|---|---|
| Работать в имеющейся feature-ветке | Пользователь выбрал выполнение здесь; ошибочный checkout затронул бы соседнюю работу |
| Генерировать фикстуры доступным Python | Dependency loader отсутствовал; DOCX/PDF всё равно отрендерены и осмотрены; переносимость среды ограничена |
| Запретить text/CRLF-конверсию фикстур | SHA256 должен соответствовать байтам на Windows/Linux; обычные бинарные файлы не меняют поведение |
| Ограниченный JAXP DOM/SAX вместо Android pull parser | Общие JVM/Android тесты без зависимости; XML ограничен размером, глубиной и узлами, DTD запрещён; API 26 ещё не проверен |
| Изолированный applicationId для QA | Сохранить подпись и данные основного приложения; поведение основного пакета на устройстве отдельно не доказано |
| Прямой AndroidJUnitRunner через adb | Offline UTP отсутствует; результат проверен по числу тестов; CI connected-путь остаётся непроверенным |
| Package `importer` | `import` — ключевое слово Kotlin; контракт DTO сохранён, пути плана уточнены |
| Descriptor/media hashes в квитанции | Подтвердить прежнюю публикацию после удаления оригинала, отклонить изменённый intent/медиа; формат квитанции расширен с defaults |
| Навигация UUID + ordinal | Стабильные номера страниц/блоков, без путей; изменение алгоритма разбиения потребует сохранять совместимость ссылок |
| Watchdog дискового теста 30 вместо 5 секунд | Совместный lint/JVM прогон не уложился в 5 секунд, изолированный тест прошёл; лимиты приложения не менялись, зависание теста обнаружится позже |
| Частичная приёмка устройства/OCR | API 26, полный lifecycle камеры/службы и реальная модель не проверены; возможные платформенные/OCR ошибки остаются до приёмки |
| Повторный разбор сравнивается по источнику | Пользователь видит прежние версии и подтверждает добавление новых; общая страница может содержать несколько разных задач |

Отложенных minor-замечаний ревью нет. Автоматический поиск примеров агентом, embeddings и
автоматический RAG остаются отдельным этапом. Проверка API 26, recreation во время file/camera
picker, «Домой» при длительном реальном импорте, системный timeout/отказ foreground-службы и
качество OCR не объявляются выполненными. Эти пробелы сохраняются в плане и backlog.
