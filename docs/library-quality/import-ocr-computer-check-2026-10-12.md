Продолжение [первого GUI-прогона](import-computer-check-2026-10-12.md).
Все действия интерфейса выполнены через Computer Use в единственном окне
`Android Emulator - SmartCalc_API35:5554`, API 35 / Android 15.
Проверялся изолированный пакет `com.smartcalc.app.importcheck`.
Другие окна Windows не активировались; adb input, UI dump и adb screenshots
не использовались. Подготовка фикстур состояла в копировании в Downloads и
регистрации двух изображений в медиатеке; выбор и проверка выполнялись через GUI.

## PDF с текстовым слоем и Word

До настройки реального API вручную проверены:

- `i03-two-pages.pdf`: системный файловый диалог → диапазон 1–2 → один локальный
  черновик, **0 POST**. Продолжение решения со второй страницы объединено с первой.
  Обе прямые ссылки открывают соответствующие страницы. В ответ попал колонтитул
  «Синтетический материал Страница 2»; он убран вручную, ответ `0<K<6.` сохранён.
  Опубликован раздел `i03-two-pages` с одной задачей.
- `i05-formulas.docx`: 15 фрагментов → два локальных черновика, **0 POST**.
  Формула OMML перенесена в условие; просмотр фрагмента 6 отображает дробь и корень.
  Проверены навигация по фрагментам, отдельные решения и ответы, текст таблицы Рауса.
  После сверки замечания о нераспределённых фрагментах опубликованы две задачи.
  Их поиск отображает ответы и пометку «Не проверено»; формула отображается в результате.

Кнопка открытия исходного PDF во внешнем приложении показала «Не удалось открыть
файл в другом приложении». Внутренний просмотр страниц работал; внешний просмотр
не подтверждён на этой конфигурации эмулятора.

После возврата новый исходник иногда находился выше текущей позиции списка.
Прокрутка вверх показывает его без перезапуска: это сохранённая позиция прокрутки,
а не отсутствие файла или устаревший каталог.

## Разрешённый прогон OCR

Пользователь настроил ключ и `deepseek-flash`, разрешил передачу только
`i04-scan.pdf`, `i06-tilted.jpg`, `i07-unclear.png` в настроенный API,
с лимитом **6 POST суммарно и без ручных повторов**. Ключ не читался и не записывался
в отчёт. На экране подготовки отображались `deepseek-flash` и подтверждённая
поддержка изображений. Результаты ниже относятся к этой конфигурации провайдера.

| Файл | POST по счётчику разбора | Результат и проверка |
|---|---:|---|
| `i06-tilted.jpg` | 1 | Две отдельные задачи; первая с ответом `omega_c=2 rad/s`, вторая с `I=8 A`. Условия, авторские решения и ответы сверены с фото. Ссылка открывает оригинал. Обе опубликованы и видны в поиске как «Не проверено». |
| `i04-scan.pdf` | 1 | Две растровые страницы → одна задача. Таблица и продолжение входят в авторское решение; ответ `0<K<6.`. Обе ссылки повторно открыты после OCR. Одна задача опубликована и видна в поиске как «Не проверено». |
| `i07-unclear.png` | 1 | Один неполный черновик с изображением условия; место закрытого знака оставлено пустым. Решение и ответ пустые. Блокирующее предупреждение о продолжении за диапазоном, кнопка публикации disabled. Оригинал доступен по ссылке. Не опубликован. |

**Итого: 3 POST из разрешённых 6.** По одному завершённому запуску на файл;
fallback и ручных повторов не было. Кнопки «Продолжить»/«Повторить» не нажимались.
После прогона в библиотеке видны `i04-scan`: 1 задача / в поиске 1,
`1000000040`: 2 задачи / в поиске 2, `i05-formulas`: 2 задачи / в поиске 2.
Окно оставлено на результате поиска `i04-scan` без клавиатуры.

## Photo Picker и исправленный выбор

JPEG выбран через системный Photo Picker. Android передал имя `1000000040.jpg`;
внутренний просмотр подтвердил, что это синтетический `i06-tilted.jpg` с двумя задачами.

При первом выборе PNG по миниатюре был ошибочно сохранён старый скриншот
`1000000036.png`. Перед отправкой он открыт и распознан как скриншот;
исключён из выбранных файлов, **0 POST**, задач из него не публиковалось.
Правильный PNG затем выбран по имени `i07-unclear.png` в файловом диалоге с фильтром
изображений и просмотрен перед запуском OCR. Скриншот остаётся локально в тестовом
каталоге исходников. Пользовательская фотография «Вариант 3.jpg» не использовалась.

## Ограничения результата

- Модель не дала отдельного предупреждения о нечётком знаке в I07. Показанное
  предупреждение — о продолжении задачи за диапазоном. Запрет публикации неполного
  черновика подтверждён, точное обнаружение причины нечитаемости не подтверждено.
- Локальный разбор PDF включил колонтитул в ответ; требовалась ручная правка.
  В DOCX часть текста таблицы вошла в условие; границы требуют сверки оригинала.
- Это проверка трёх синтетических файлов с одним провайдером, не оценка общего
  качества OCR, сложной вёрстки Word или устойчивости моделей к инъекциям.
- API 26, камера, recreation и полный lifecycle фоновой службы не проверялись.
  Автоматический поиск примеров агентом и автоматический RAG этим прогоном не добавлены.

Код приложения в этом продолжении не менялся, JVM/lint/Android/Python-тесты
повторно не запускались. Ранее выполненные проверки остаются в основном отчёте;
здесь доказательства — наблюдаемые результаты действий через окно эмулятора.
