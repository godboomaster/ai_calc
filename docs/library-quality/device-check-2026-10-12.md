# Проверка метаданных библиотеки на эмуляторе

> **Исторический отчёт, 2026-10-12** (дополнения датированы отдельно). Результаты относятся
> к указанным ниже исходникам и сценариям; они не подтверждают все последующие версии.
> Текущие статусы — в [бэклоге](../backlog.md), назначение документов — в [карте](../README.md).

Дата: 2026-10-12. Код: `c6c9900` / документация: `a48fe6e`, ветка `codex/library-metadata`.
Устройство: SmartCalc_API35, Android 15 / API 35, x86_64, экран 720×1280, плотность 280 dpi.

## Установка и сохранность данных

Основной пакет `com.smartcalc.app` обновлён через `adb install -r`, без удаления и очистки.
Проверочный debug APK переподписан прежним локальным ключом: сертификат совпал с установленным
приложением и `release-signing.sha256`. Название осталось «Калькулятор», версия — 1.1.0,
как у ранее установленной копии эмулятора. Это локальная проверочная сборка, не новый релиз.

Настройки API не открывались; API-ключ не читался, не менялся и не использовался для запросов.
Два прежних решения были видны в поиске после обновления, перезапуска и завершения проверки.
В библиотеке до проверки задач не было. Созданный тестовый раздел и его файл удалены после
проверки; пользовательские задачи, фото и файлы не удалялись. Калькулятор возвращён к исходному 0.

## Проверенные сценарии

Все действия выполнены в интерфейсе приложения через Android input/UI Automator,
с проверкой дерева доступности и снимков экрана; данные — один синтетический пример.

| Сценарий | Результат |
|---|---|
| Импорт JSON через системный выбор файла | Раздел появился, источник содержит имя файла, версия 1, статус «Не проверено» |
| Ручная отметка «Проверено мной» и сохранение | Отметка сохранилась после повторного открытия |
| Повторный импорт того же файла | Одна задача, прежняя отметка и версия; дубликат не появился |
| Изменение решения | Отметка сбросилась; после сохранения появилась версия 2 |
| Просмотр предыдущей версии | Видны исходное условие, ответ и прежняя отметка проверки версии 1 |
| Выключение / включение поиска | Запрос DeviceCheck перестал находить пример и снова нашёл его после включения |
| Статус «Отклонено» | Пример исключён при исходно включённом поиске; UI объясняет исключение |
| Принудительная остановка процесса и новый запуск | Сохранились версия 2, предыдущая версия и статус «Отклонено» |
| Импорт исходного файла после локальной правки | Показана ошибка конфликта; версия 2, правка и статус остались на месте |
| Удаление тестового раздела | Библиотека вернулась к исходному пустому состоянию, прежняя история доступна |
| Обычный калькулятор | 2 + 3 = 5; дисплей затем очищен до исходного 0 |

Сбоев приложения в этих сценариях не обнаружено. Журнал crash для текущего процесса пуст.
Поля, меню статуса, переключатель и архив версии доступны на экране; длинный редактор прокручивается,
шапка остаётся на месте. Изменения продуктового кода после этой проверки не потребовались.

## Границы проверки

Это проверка основных сценариев на одном эмуляторе. Миграция непустой старой библиотеки,
архив фотографий, конкурентные редакторы и ошибки записи отдельно проверены JVM-тестами;
в этом ручном прогоне на Android они не воспроизводились. Не проверялись API, OCR,
импорт сборников PDF/DOCX, производительность на 500 задачах и реальные телефоны.

Локальные снимки и вспомогательный сценарий находятся в игнорируемом каталоге
`build/library-metadata/device/`: `verified-draft.png`, `versions.png`, `disabled-search.png`,
`unverified-search.png`, `persisted-rejected.png`, `conflict-import.png`, `calculator-result.png`.
APK и снимки не включены в репозиторий.

## JVM-проверки переноса task-search и метаданных — 2026-10-12

Перенесено из README проверочного набора без изменения результатов. Для метаданных
код и документация указаны в начале отчёта; перенос task-search выполнялся на базе
`0425c65` по [плану](../superpowers/plans/2026-10-12-task-search-integration.md).
Точный коммит каждого JVM-прогона в исходной записи не указан.

Перед исправлением восемь регрессий поиска/ключей воспроизвели дефекты: потерю знака,
интегратора и степени, неверный приоритет модуля, числовое совпадение при отсутствующей теме,
ключи фото по позиции и склеивание разных фотографий. Отдельно воспроизведено исчезновение
дополнений из поиска для уже открытого библиотечного примера.

`TaskSearchRegressionTest` проверяет эти случаи и поиск по собственной истории; тесты
`HistoryStoreTest` и `TemplateStoreTest` проверяют независимые фотографии, общие ссылки,
сбой копирования/записи и одинаковый размер разных изображений. Тесты не читают ключи и
не вызывают API. Это регрессионная проверка переноса, а не приёмка по всем Q01–Q22.

Независимое ревью дополнительно выявило потерю контекста фото при вопросе к библиотечному
решению. `FoundSolutionFollowUpTest` проверяет JSON-запрос с фотографиями условия и решения,
отсутствие дублей, отказ при пропавшем/слишком большом вложении и прежний текстовый сценарий
для уже распознанной ИИ задачи. Проверка не отправляет эти сообщения в сеть.

Ограничения текущего поиска: нет математического доказательства эквивалентности формул,
общего разбора LaTeX, семантических векторов, выделения ролей чисел и конвертации единиц.
Фотографии входят в ключ примера, но их содержимое без текстового описания не распознаётся.
Целевой p95 для 500 задач пока не измерен на устройстве.

Итог локального прогона переноса (2026-10-12): **181 JVM-тест, 0 падений/ошибок**,
`lintDebug` — 0 ошибок и 46 предупреждений, `assembleDebug` — успешно. Независимое
ревью закрыто после исправлений. Устройство и реальный API в этом прогоне не использовались.

Пакет метаданных библиотеки (2026-10-12): **198 JVM-тестов в 29 наборах**, без падений,
ошибок и пропусков; `lintDebug` — 0 ошибок и 46 предупреждений; `assembleDebug` — успешно.
Добавлены проверки миграции, устойчивых ID и версий, сохранения старых фото, ручной проверки,
блокировки повреждённого хранилища, повторного/конфликтующего импорта, устаревшего редактора,
а также исключения примеров из поиска без обхода через исторические снимки.
Это не проверка OCR, качества RAG или скорости на 500 задачах; устройство и API не использовались.

Дополнительно выполнена [проверка UI на Android-эмуляторе](#проверенные-сценарии):
импорт, статусы, версии, поиск, повторный импорт и перезапуск прошли. Основное приложение
обновлено с прежней подписью без очистки данных; реальные API-запросы не выполнялись.
