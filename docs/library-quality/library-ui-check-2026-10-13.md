## Изменения

- Разделены действия «По образцу» (метод для одной новой задачи), «Оформление» (вид и
  подробность новых ответов до сброса) и «Библиотека» (хранение и поиск готовых задач).
- В библиотеке появились вкладки «Поиск», «Задачи», «Файлы» и единый экран добавления:
  документ, галерея, камера, готовая подборка, ручной ввод.
- Пояснения используют отдельные Material 3-карточки: заголовок, короткий основной текст,
  16 dp внутренних отступов и 8 dp между элементами. Форматы и ограничения раскрываются
  отдельно, без анимации. Разборы, требующие внимания, и замечания к задачам видны раньше.
- Исправлены два подтверждённых дефекта: пропущенные моделью сегменты сохраняются как
  редактируемый черновик с блокирующим замечанием; текст из заголовка задачи остаётся в условии.
  Восстановление учитывает предыдущее продолжение и его изображения, не отправляя новый POST.

без UI-автоматизации через adb. Обновлена только изолированная копия

   на одну задачу, «Оформление» — сохранение до сброса. Подробности раскрываются отдельными абзацами.

   существующие разделы и оригиналы доступны.

   Черновик не изменялся, публикация не запускалась.
4. «Добавить материал» доступно из поиска и файлов. «Документ» разрешает PDF и DOCX;
   выбор существующего `i03-two-pages.pdf` открывает подготовку с двумя страницами,

5. Отмена системного выбора готовой подборки и фотографий возвращает на экран добавления.

8. «Ввести вручную» открывает редактор нового раздела с условием/решением; пустой ввод закрыт без сохранения.
9. Стрелка из библиотеки возвращает к калькулятору. Прежнее решение `0<K<6` осталось в истории

## Ограничения

Этот прогон не проверяет API 26, увеличенный системный шрифт, новый снимок камеры,
пересоздание процесса во время системного выбора файла или качество реального OCR после исправления.
Восстановление пропущенного материала проверено JVM-тестами, включая checkpoint контроллера.
Сохранение места библиотеки после выхода к калькулятору и отдельный просмотр найденного
примера без замены текущего решения остаются в бэклоге. Автоматический RAG не добавлялся.
