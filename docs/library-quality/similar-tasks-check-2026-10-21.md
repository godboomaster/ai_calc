Задача в бэклоге: [подбор похожих задач](../backlog.md#similar-tasks). Сценарий для пользователя —
в [README](../../README.md#похожие-задачи-перед-отправкой).

Исходники: ветка `formula-search`, коммит `e2efea0`. Его база — `196af32`: `main` (`631eacf`)
и поиск по формуле (`dab70c0`). Автотесты и проверка на эмуляторе выполнялись на рабочей копии

## Чем читать фото: Tesseract или модель

Перед реализацией проверялось, хватит ли распознавания без модели. Взяты все 153 условия из
[`examples/mmus-tasks.md`](../../examples/mmus-tasks.md), отрисованы как печатный текст с формулами
(для 25 формул из-за ограничений отрисовщика остался простой текст) и искажены как фото: наклон
до ±3,5°, перспектива, неровный свет, размытие, шум, JPEG 70, длинная сторона 1280 px.
Распознавание — Tesseract 5.5.3, `rus+eng`. Распознанный текст подавался в поиск
приложения (`TaskSearch`) по той же библиотеке на JVM.

| Текст запроса | Та же задача в топ-3 | Задача того же типа в топ-3 (без самой задачи) |
|---|---|---|
| Точный текст условия | 150/153 | 125/129 |
| Tesseract fast, ровный скан | 148/153 | 125/129 |
| Tesseract fast, «фото» | 130/153 | 117/129 |
| Tesseract best, «фото» | 130/153 | 116/129 |

Тип задачи определялся по названию раздела, разделы «КР 1» со смешанными задачами в оценку
похожих не входили. Слова условия распознаются почти без ошибок. Формулы теряются:
`12s^4 + 2s^2` читается как `125% + 252`, дроби — как случайные символы.
Две фотографии рукописных решений Tesseract не прочитал совсем (пустой результат).
Время — 0,15–0,3 с на фото на Mac. Языковые данные: fast — около 8 МБ, best — около 30 МБ.

Границы: картинки синтетические и совпадают по тексту с библиотекой, настоящие фото листов не
проверялись, на телефоне скорость не измерялась. По решению пользователя основой выбрана модель
из настроенного подключения. Tesseract не встроен.

## Ранжирование при других формулировках

Проверялось, находятся ли задачи того же типа, если условие сформулировано иначе. Использовались
15 новых задач, которых нет в библиотеке, по всем темам ММУС. Для каждой вручную написано
описание в том виде, в каком его должна вернуть модель: условие, тип, ключевые слова и разделы
из списка библиотеки. Поиск — `SimilarTasks.rank` по 153 задачам ММУС, вывод — до 8 задач.

| Чем ищем | 1-я того же типа | Того же типа в топ-3 |
|---|---|---|
| Только слова условия | 9/15 | 25/45 |
| Условие, тип и ключевые слова | 14/15 | 38/45 |
| То же и разделы библиотеки | 15/15 | 43/45 |

Границы: описания написаны агентом-разработчиком, а не получены от модели; ответы реальных
моделей могут отличаться. Набор и временный тест в репозиторий не сохранены. Это проверка
устройства ранжирования, а не измерение качества конкретной модели.

## Проверка на эмуляторе

Эмулятор запущен только для чтения (`-read-only -no-snapshot-save`), изолированный пакет
`com.smartcalc.app.importcheck`. Библиотека ММУС загружена из `examples/mmus-library.zip`
временным инструментальным тестом, подключение указывало на локальную заглушку API через
`adb reverse` (`http://127.0.0.1:8765/v1`). Заглушка возвращала фиксированные описание задачи
и решение и записывала состав запросов. Временные тест и заглушка в репозиторий не входят.

| Сценарий | Результат |
|---|---|
| Текстовая задача → экран «Похожие задачи» | Открылся, найдены задачи по Лапласу, условие показано формулами |
| «Посмотреть решение» | Полноэкранный просмотр с условием, графиком и решением |
| Две отметки → «Отправить с отмеченными (2)» | В запросе два примера и фото примера, поля `tools` нет; ответ на дисплее |
| «Назад» на экране выбора | Ничего не отправлено, текст вернулся в строку ввода |
| Фото с камеры | Превью снимка, «Модель прочитала:», найденные задачи |
| «Отправить без примеров» | В запросе только фото задачи, без примеров |
| Код задан и набран, экстренное скрытие на экране выбора | Обычный калькулятор без ✦, запрос решения не отправлен |

Не проверено: реальные модели (DeepSeek, MiMo, OpenAI) и их ответы, поворот экрана и гибель
процесса на экране выбора, галерея и документы на устройстве, API 26. Сборка с этим кодом
установлена на телефон пользователя (версия в приложении 1.6.5, debug), там проверки не проводились.

Во время проверки после выхода из изолированного пакета на передний план вышел основной
`com.smartcalc.app` из снимка эмулятора, и несколько нажатий попали в него: выдано разовое
разрешение камеры и начат запрос, который остановился с «API-ключ не задан» до отправки.
Эмулятор работал без сохранения состояния, снимок `default_boot` не изменился. Дальше перед
каждым нажатием проверялось, какое приложение на переднем плане.
