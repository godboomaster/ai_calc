## Диагностика без новой отправки

По коду запроса и [официальному контракту DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/)
установлен конфликт параметров: первый запрос принудительно выбирает
search_examples через именованный tool_choice, но не задаёт thinking.
На официальном API thinking включён по умолчанию; выбор конкретного инструмента
в этом режиме запрещён и возвращает HTTP 400. Имя deepseek-flash корректно,
сама модель поддерживает инструменты. Удаление response_format при штатном
fallback не меняло конфликтующую комбинацию. Это вывод из исходного запроса и
документированного контракта: исходное тело HTTP-ошибки приложение не сохранило,
поэтому дословное сообщение сервера восстановить нельзя.

Исправление: только для agent tools на точном хосте api.deepseek.com выставляется
thinking.type=disabled во всех обменах. Именованный поиск, ограничение POST и
JSON fallback сохраняются. Прочие провайдеры и запросы без инструментов не
получают этот параметр. Такое решение использует режим инструментов без thinking;
поддержка thinking с передачей reasoning_content остаётся отдельным расширением.

Установлены также два дефекта диагностики приложения:

- LibraryAgentLoop заменял любой 400/422 после fallback на утверждение об
  отклонении инструментов моделью и терял HTTP-код. Теперь сохраняются статус
  и число POST; сообщение нейтрально описывает отклонение параметров.
  Сырое тело сервера не публикуется и не записывается, чтобы исключить отражение ключа.
- CalculatorScreen ограничивал сообщение через MathText/maxLines=4, поэтому
  конец исчезал. Теперь краткий текст имеет явное многоточие и кнопку «Подробнее»;
  полный текст доступен в выделяемом прокручиваемом диалоге без сетевых действий.

Диагностика и исправление не отправляли дополнительных POST к реальному API.
Проверка успешного живого сценария после исправления пока не выполнялась.

Локальная проверка исправлений: **304 JVM-теста / 43 набора, 0 failures/errors**;
lint **0 ошибок / 7 предупреждений**; обычный и isolated APK собраны.
Независимое ревью подтверждённых дефектов не нашло. Регрессии проверяют точный
хост DeepSeek, thinking во всех обменах и при JSON fallback, сохранение forced

провайдеров и запросов без tools параметр thinking отсутствует.

GUI-проверка исправления выполнена в том же окне эмулятора через «Компьютер».
