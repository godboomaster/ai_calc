## Подготовка через интерфейс

Выбрано единственное окно Android Emulator - SmartCalc_API35:5554. Все действия
в приложении выполнялись через sky; ADB, чтение файлов приложения и логов не
использовались. Ключ не раскрывался. В настройках видны base URL
https://api.deepseek.com и модель deepseek-flash. Включён и сохранён переключатель
поиска агента в библиотеке; «Проверить соединение» не нажимали.

Вручную создан раздел «SYNTHDS20261013 — синтетический тест» с одним примером:

- Условие: SYNTHDS20261013. На резисторе R=2 Ом напряжение U=6 В. Найти силу тока.
- Решение: по закону Ома I=U/R=6/2=3 А; для новой задачи подставить новые U и R.
- Ответ: 3 А; версия 1, ручной ввод, статус «Не проверено», использование в поиске включено.

Локальный поиск по SYNTHDS20261013 показал только этот пример. Затем дисплей
очищен; введена новая задача без дополнения к прежнему ответу и без вложений:

> Синтетический тест SYNTHDS20261013. Найди похожую задачу: вызови search_examples
> с query="SYNTHDS20261013" и limit=1, затем read_example для найденного примера.
> Другие примеры не ищи и не читай. После чтения реши новую задачу: на резисторе
> R=4 Ом напряжение U=20 В. Найди силу тока. Используй метод примера, но новые
> числа. Если пример не найден или не прочитан, явно сообщи об этом.

Ожидаемый итог новой задачи: 5 А. Кнопка отправки нажата один раз.
