# Перенос task-search на актуальный main

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Scope and commits are authorized by the user.

**Goal:** перенести ручную библиотеку и поиск из `5f1440e` на `0425c65`, исправить найденные дефекты и честно отразить готовность RAG в бэклоге.

**Architecture:** сохранить локальные JSON-хранилища и текущий Compose-интерфейс. Это основа для будущего RAG, без нового сетевого API и автоматического импорта сборников.

**Tech Stack:** Kotlin, Compose, kotlinx.serialization, JUnit, Android Gradle.

**Spec:** `docs/superpowers/specs/2026-10-12-library-rag-design.md` — будущая цель; этот перенос выполняет только её базовую часть.

## Ограничения и решения

- Сохранить исправления main: атомарные записи, защиту импортов, обработку фотографий, независимые состояния калькулятора и помощника, ввод поверх калькулятора, сворачивание решения и последний экран ответа.
- Не читать API-ключи, не выполнять реальные запросы, не удалять данные установленного приложения.
- Работать в `codex/task-search-integration`, основанной на main с сохранённым коммитом документации `7684d33`; пользовательскую фотографию не включать.
- Идентификатор найденного примера должен зависеть от содержимого, включая фотографии, а не позиции или пути. Редактирование даёт новую версию снимка истории. Полная модель версий остаётся будущей задачей RAG.
- Коммиты уже разрешены пользователем. Публикация не входит в задачу.
- Порядок коммитов исправлений: сначала поиск с общим ExampleFingerprint, затем хранилища, которые используют его для прикрепления. Ревью добавило исправление мультимодального контекста дополнений отдельным коммитом.

## Проверка рисков

- Удаление источника не повреждает открытое решение; удаление истории не повреждает соседние записи.
- Ошибка записи не меняет состояние и не оставляет новые фотографии.
- Перестановка примеров не меняет идентификатор; замена фотографии меняет снимок.
- Одинаковые по размеру разные фотографии не склеиваются.
- Формулы с разным знаком, дополнительным s в знаменателе и модулем различаются; пустой запрос по-прежнему показывает список.
