## Воспроизводимые тесты

`KoogRecoveryTest` запускается и на JVM, и на Android. Используются настоящий
Koog transport, локальный MockWebServer, RequestRunner, RequestJournal,
RequestFiles и HistoryStore в отдельных временных каталогах. Только фиктивный ключ.

1. Получение ответа без наблюдателя экрана, одна запись в истории и один POST.
2. Потеря coroutine scope во время HTTP: повторное открытие журнала даёт
   `INTERRUPTED`, сохраняет входные данные и не отправляет дополнительный POST.
3. Остановка после `read_example`, до финального POST: отчёт с двумя отправками
   и прочитанным примером остаётся на диске. Только явный новый запуск отправляет
   запрос; на диске нет ключа или reasoning модели.
4. Повторное восстановление сохранённого дополнения, в том числе если история уже
   записана, но журнал ещё RUNNING: один исходный ответ и одно дополнение, без сети.

Эти тесты моделируют потерю scope и повторное открытие файлов в одном процессе;
фактическое завершение процесса проверено отдельно через интерфейс на API 35.
Восстановление не продолжает старую переписку с инструментами автоматически.
При отсутствии готового ответа пользователь запускает новую попытку явно.

Команды из корня репозитория:

```powershell
./gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug -PisolatedDeviceCheck -PkoogProbe --max-workers=2
adb -s emulator-5554 shell am instrument -w -e class com.smartcalc.app.data.api.KoogGenerationTest,com.smartcalc.app.data.api.KoogRecoveryTest com.smartcalc.app.importcheck.test/androidx.test.runner.AndroidJUnitRunner
```

Полный JVM-набор: **348 тестов, 0 ошибок**; сборка и lint успешны.
На API 35: **OK (13 tests)**, 3.339 с.
