# SmartCalc

Android-калькулятор со скрытым ИИ-помощником. Снаружи — обычный калькулятор, а значок в углу
превращает его клавиши в инструменты ИИ: задачу можно сфотографировать, выбрать из галереи,
загрузить документом или просто написать на дисплее. Ответ появляется прямо в строке результата.

## Возможности

- **Калькулятор** — обычный счёт: скобки, проценты, десятичные дроби.
- **Режим ИИ** — значок ✦ в правом верхнем углу превращает цифры 1–9 в действия: 1 Написать,
  2 Камера, 3 Галерея, 4 Документ, 5 История, 6 Настройки, 7 По образцу, 8 Оформление, 9 Библиотека. Остальные
  клавиши калькулятора работают как обычно.
- **Ввод с дисплея** — в режиме ИИ или при показанном ответе нажатие на дисплей открывает
  системную клавиатуру поверх кнопок калькулятора. Пока решение скрыто и показан обычный
  калькулятор, дисплей не открывает ввод. Написать задачу можно через ✦ → «Написать».
  Поле появляется на месте результата; системная кнопка отправки считает выражение или отправляет текст задачи ИИ.
  Закрытие клавиатуры сохраняет черновик.
- **Ответ на дисплее** — пока ИИ решает, бегут точки; потом в строке результата — ответ.
  Пока показан ответ, удержание цифры открывает шаг (1–9, 0 — десятый), удержание `=` — всё решение.
  Шаг открывается отдельным экраном: шапка и стрелки закреплены, содержимое прокручивается; «Шаг … из … ▾» открывает
  список всех шагов и итоговую страницу «Ответ». Стрелка слева и «Назад» возвращают краткий ответ.
- **Полное решение** — условие, шаги и ответы можно сворачивать по отдельности или все сразу;
  состояние сохраняется. В отдельном экране шага содержимое остаётся развёрнутым.
- **Пауза в чтении** — кнопка калькулятора в шапке шага или полного решения возвращает
  сохранённый расчёт. Удержание ✦ или включённый свайп возвращают тот же экран и место чтения.
  При переключении шагов каждый сохраняет свою прокрутку. Новая задача, дополнение или выбор
  записи из истории начинают новый сеанс чтения.
- **После перезапуска** — приложение открывается обычным калькулятором с сохранённым расчётом.
  Удержание ✦ или включённый свайп возвращают выбранное решение, шаг и место чтения.
  Черновики новой задачи и дополнения сохраняются даже при закрытии с открытой клавиатурой:
  новая задача доступна через ✦ → «Написать» или тап по дисплею в режиме ИИ.
  Дополнение открывается нажатием на показанный краткий ответ; скрытое решение не включает ввод.
  Стрелка слева или «Назад» из чтения сохраняют возврат именно к краткому ответу.
  Прерванный запрос и его ошибка также сохраняются; удержание ✦ открывает состояние и кнопку повтора.
- **Фоновое выполнение** — запрос продолжает работать после «Домой», закрытия экрана и удаления
  приложения из недавних. Пока идёт вычисление, Android показывает тихое системное уведомление
  без условия задачи и ответа. Разрешение на уведомления запрашивается при первом вычислении;
  отказ не запрещает выполнение сервиса, но Android может показывать его только в списке активных приложений.
  Результат сохраняется в историю, а после запуска доступен через ✦. Фото, документ и контекст
  подготовленного запроса сохраняются приватно для ручного повтора; API-ключ в журнал не записывается.
  «Принудительно остановить», перезагрузка устройства или остановка процесса системой обрывают
  сетевое соединение: после запуска показывается «Прервано». Автоматического повторного платного
  запроса нет. Если ответ уже получен и записан локально, приложение завершает его сохранение без
  повторной отправки. Для нового запроса или выбора записи из истории предыдущее вычисление отменяется.
- **Счёт во время решения** — обычная клавиша возвращает сохранённый расчёт и сразу выполняет
  своё действие. `C` при показанном помощнике только скрывает его; повторное `C` очищает расчёт.
  Ответ или ошибка приходят тихо: точка на ✦ остаётся до просмотра. Удержание ✦ возвращает
  ожидание, ответ или ошибку. В обычном калькуляторе точки на цифрах и доступ к шагам скрыты.
- **Возврат свайпом** — в настройках можно включить «Возврат к решению свайпом» (по умолчанию
  выключен). Свайп вверх по дисплею калькулятора возвращает помощника, как удержание ✦.
  Переключатель сохраняется сразу; в редакторе и при просмотре ответа жест не действует.
- **Код кнопки ✦** — в настройках можно задать код из 2–12 цифр. Без кода ✦ видна всегда. С кодом
  набор кода на калькуляторе и «=» показывает ✦, повторный набор снова прячет её вместе со строкой
  ввода задачи, свайпом и ответом на дисплее; сам код считается как обычное число. Показана кнопка
  или спрятана, сохраняется и после перезапуска приложения. Новый код сразу кнопку не прячет.
- **Дополнения** — нажатие на ответ на дисплее открывает строку для следующего вопроса к нему.
  ИИ получает всю цепочку (задача, ответ, прежние дополнения), а ответ на дополнение снова
  появляется на дисплее. Черновик дополнения не меняет сохранённый расчёт. ✕ над строкой
  переключает ввод на новую задачу; отправка новой задачи заменяет текущий ответ помощника.
- **Шаблоны заданий** — примеры решённых задач одного типа (условие и решение текстом, фото или
  документом) и требования к ним. Выбранный шаблон уходит ИИ вместе со следующей задачей или
  дополнением, и ответ даётся так же, как в примерах. Дополнения к задаче, решённой по шаблону,
  тоже уходят с ним. Шаблоны экспортируются и импортируются файлом: ZIP или JSON (с фото) и
  Markdown (только текст; такой файл можно написать и вручную — «# Название», «## Требования»,
  «## Пример 1», «### Условие», «### Решение»). Образцы файлов и описание `manifest.json` —
  в [`examples/`](examples).
- **Библиотека** — поиск готовых решений, свои задачи, импорт файлов с оригиналами и проверкой разбора; [подробнее ниже](#библиотека).
- **Документы** — PDF (первые 4 страницы уходят картинками), DOCX и TXT (текстом), изображения.
- **Оформление** — формулы LaTeX рисуются как в учебнике, таблицы markdown — таблицами,
  графики строятся по формулам (с логарифмической шкалой и годографами), схемы — из SVG.
- **Формат решения** — свои требования к оформлению текстом и/или фото образца.
- **История** — все решения сохраняются на телефоне.

## Библиотека

Вход **✦ → 9 «Библиотека»** открывает вкладку **«Поиск»** по библиотеке, образцам и истории.
Вкладка **«Задачи»** содержит разделы, редактор и экспорт ZIP/JSON/структурированного Markdown;
**«Файлы»** — оригиналы и разборы. В обычном режиме клавиша 9 остаётся цифрой.

В помощнике разделены три назначения: **«По образцу»** задаёт метод и примеры для одной новой
задачи, **«Оформление»** — структуру и подробность ответов до сброса, **«Библиотека»** хранит
решённые задачи для поиска. При добавлении задач в образец создаются независимые копии.

На каждой вкладке есть единый вход **«Добавить материал»**: документ (PDF/DOCX/текст/Markdown),
галерея, камера, готовая подборка (ZIP/JSON/структурированный Markdown) или ручной ввод.
Выбор документа сохраняет оригинал и открывает подготовку; распознавание не запускается автоматически.
Короткие пояснения вынесены в карточки с заголовками, подробности и ограничения раскрываются
по нажатию без анимаций. Незавершённые разборы находятся перед оригиналами, завершённые —
в раскрываемом списке. Замечания проверки стоят перед полями и фотографиями задачи.

### Задачи и версии

Задачи объединяются в разделы, добавляются вручную с фото или загружаются готовой подборкой.
Форматы и образцы файлов описаны в [examples](examples/README.md). Раздел можно прикрепить
к образцу значком 🔗; его задачи станут независимыми примерами для запросов по этому образцу.

У каждого примера в редакторе базы есть источник, номер версии, выбор «Не проверено» /
«Проверено мной» / «Отклонено» и переключатель «Использовать в поиске». Проверку ставит
только пользователь; правка текста/фото снимает прежнее подтверждение. После редактирования
можно явно проверить новую версию. Предыдущие версии с фото доступны здесь же для чтения.
Название раздела и переключение статусов не увеличивают номер версии содержимого.

Непроверенные примеры видны в поиске с пометкой. Отклонённые и выключенные не участвуют;
их ранее открытые копии остаются в истории, но не возвращаются как отдельные поисковые
результаты. Самостоятельные примеры шаблонов и собственные ответы ИИ независимы от этой отметки.

Одинаковый повторный импорт оставляет локальные статусы и фото. Если раздел с тем же ID
отличается, импорт целиком отклоняется с объяснением и сохраняет прежние данные. Экспорт
переносит текущее содержимое; архив версий и личная проверка остаются на устройстве.
Ошибка чтения блокирует изменения библиотеки. Ошибка сохранения оставляет черновик открытым.

### Импорт и оригиналы

Во вкладке **«Файлы»** сохраняются оригиналы PDF, DOCX, TXT/Markdown и JPEG/PNG. Фото можно выбрать
или снять камерой. Перед запуском пользователь выбирает порядок файлов и диапазон страниц/блоков;
видны предел партии и необработанный остаток. Структурированный текст разбирается локально,
распознавание остальных фрагментов использует настроенный API после явного запуска.

Экран **«Проверка разбора»** позволяет править условие, авторское решение и отдельный ответ,
распределять ссылки, объединять/разделять/исключать черновики и добавлять выбранные в раздел.
Блокирующие замечания требуют явной проверки. Длинное продолжение, не помещающееся в пакет,
остаётся редактируемым черновиком вместе с рисунками. Проверка разбора не подтверждает математику.
Материал, пропущенный в ответе модели, также остаётся черновиком с блокирующим замечанием,
включая текст и изображения предыдущего продолжения. Дополнительный запрос автоматически не отправляется.
Локальный разбор сохраняет содержательный текст заголовка «Задача 1. Найти …» в условии.

Ссылка открывает страницу PDF, изображение или блок DOCX/TXT; внешнему приложению выдаётся
временная копия выбранного оригинала. В редакторе опубликованного примера доступны ответ,
ссылки текущей и предыдущих версий. Выключение исходника исключает связанные примеры из новых
поисков. Удаление оригинала сохраняет текст задач и собственные фотографии примеров/истории.
Повтор загрузки одинаковых байтов узнаёт источник и при необходимости восстанавливает оригинал.
Обработанные диапазоны показаны во вкладке файлов и перед повторным запуском. Повторный разбор
показывает прежние примеры с общими ссылками для сравнения. Добавить его результат как новые
задачи можно только после отдельного подтверждения; прежние локальные правки сохраняются.
После остановки процесса готовые черновики остаются; неизвестный исход запроса не повторяется автоматически.
Проверки импорта и их ограничения перечислены в [карте документации](docs/README.md#исторические-проверки).

### Поиск и выбор результата

Ручной поиск работает без ИИ и без интернета: слова, числа, тип задачи, простые текстовые
формулы и фрагменты LaTeX. Числа из расчёта (`12+3.5+40`) переносятся в запрос.
Поиск охватывает библиотеку, примеры образцов и историю с дополнениями. Полной математической
эквивалентности формул, ролей чисел/единиц и распознавания содержимого фото самим поиском нет.

Нажатие на результат открывает «Просмотр задачи» с условием, решением, ответом,
фотографиями и доступными ссылками на оригинал. Просмотр не заменяет текущее решение
и не создаёт запись истории. Кнопка «На калькулятор» открывает существующую запись истории
без изменения либо сохраняет библиотечный пример в историю с собственными фотографиями.
Дополнения доступны и при повторном открытии. Ошибка сохранения остаётся на экране просмотра
и предлагает повтор; несохранённый ответ не открывается. Фотографии видны в шагах и полном решении.
Переходы сохраняют стрелку слева и отсутствие анимаций.

При дополнении к библиотечному примеру сохранённые фотографии входят в запрос вместе с
текстом; нужна модель с поддержкой фото. Недоступное вложение или объём больше 20 МБ
останавливает отправку с понятной ошибкой, а не убирается из контекста молча.

На калькуляторе выбранное решение разбивается на шаги и страницу ответа. При новом входе
через калькулятор поисковый запрос пока не восстанавливается; при переключении вкладок
библиотеки состояние поиска сохраняется.

### Поиск агентом

В настройках можно включить «Разрешить агенту поиск в библиотеке»; по умолчанию он выключен.
Тогда модель сама выбирает поиск и чтение активных библиотечных примеров. Просьба
«найди похожую задачу» требует поиска. Обязательного поиска перед каждым запросом нет;
образцы и собственная история не становятся библиотекой агента автоматически.
Инструменты передают текст; фотографии примеров ими не отправляются.

В ответе доступны «Прочитанные примеры»: сохранённые тексты, версии, статусы и имена источников.
Просмотр не заменяет текущее решение; у дополнений свои снимки. Это факт чтения,
а не подтверждение математической правильности или использования метода из примера.

## Сборка

Нужны JDK 17+ и Android SDK 35 (проще всего — Android Studio).

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # тесты
```

Путь к SDK Android Studio прописывает в `local.properties` сама; без Android Studio создайте файл
вручную: `sdk.dir=/путь/к/Android/sdk`.

## Настройка

В приложении: значок ✦ → **Настройки** → **Подключения**. Можно сохранить несколько
подключений и выбрать активное для новых запросов; начатая попытка использует своё подключение.

| Поле | Что указать |
|---|---|
| Base URL | адрес OpenAI-совместимого API, по умолчанию `https://api.openai.com/v1` |
| API-ключ | ключ от этого API; хранится только на телефоне |
| Модель | точное имя модели у провайдера; для изображений нужна модель с поддержкой фото |

Кнопка «Проверить соединение» отправляет пробный запрос с текущими полями черновика,
не сохраняя их. Для записи изменений нажмите «Сохранить». Поддержку фото включайте только
для модели, которая принимает изображения. Для совместимых API можно выбрать формат
и режим рассуждения; доступность отключения рассуждений зависит от модели.

Для внешнего API требуется HTTPS. HTTP допускается только для локального сервера
на `localhost`, `127.0.0.1` или `::1`. Настройки с API-ключом исключены из облачных
резервных копий Android и переноса данных на другое устройство; там ключ нужно ввести заново.

## Устройство проекта

```
app/src/main/java/com/smartcalc/app/
├── SolutionViewModel.kt     — координация текущего решения и UI
├── AppDependencies.kt       — сборка зависимостей процесса
├── data/
│   ├── api/OpenAiClient.kt  — запрос к модели, разбор JSON-ответа, правила для формул/графиков/схем
│   ├── session/             — хранение сеанса и правила чтения/черновиков
│   ├── request/             — выполнение, журнал и восстановление запросов
│   ├── library/             — операции коллекций, оригиналы и импорт
```
