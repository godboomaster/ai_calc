# SmartCalc

Android-калькулятор со скрытым ИИ-помощником. Снаружи — обычный калькулятор, а значок в углу
превращает его клавиши в инструменты ИИ: задачу можно сфотографировать, выбрать из галереи,
загрузить документом или просто написать на дисплее. Ответ появляется прямо в строке результата.

## Возможности

- **Калькулятор** — обычный счёт: скобки, проценты, десятичные дроби.
- **Режим ИИ** — значок ✦ в правом верхнем углу превращает цифры 1–8 в действия: 1 Написать,
  2 Камера, 3 Галерея, 4 Документ, 5 История, 6 Настройки, 7 Шаблоны, 8 Формат. Остальные
  клавиши калькулятора работают как обычно.
- **Ввод с дисплея** — нажатие на строку ввода открывает системную клавиатуру поверх кнопок
  калькулятора. Поле появляется на месте результата; системная кнопка отправки считает выражение
  или отправляет текст задачи ИИ. Закрытие клавиатуры сохраняет черновик.
- **Ответ на дисплее** — пока ИИ решает, бегут точки; потом в строке результата — ответ.
  Пока показан ответ, удержание цифры открывает шаг (1–9, 0 — десятый), удержание `=` — всё решение.
  Шаг открывается отдельным экраном: шапка и стрелки закреплены, содержимое прокручивается; «Шаг … из … ▾» открывает
  список всех шагов и итоговую страницу «Ответ». Стрелка слева и «Назад» возвращают краткий ответ.
- **Полное решение** — условие, шаги и ответы можно сворачивать по отдельности или все сразу;
  состояние сохраняется. В отдельном экране шага содержимое остаётся развёрнутым.
- **Пауза в чтении** — кнопка калькулятора в шапке шага или полного решения возвращает
  сохранённый расчёт. Удержание ✦ или включённый свайп возвращают тот же экран и место чтения.
  При переключении шагов каждый сохраняет свою прокрутку. Новая задача, дополнение или выбор
  записи из истории начинают новый сеанс чтения.
- **После перезапуска** — приложение открывается обычным калькулятором с сохранённым расчётом.
  Удержание ✦ или включённый свайп возвращают выбранное решение, шаг и место чтения.
  Черновики новой задачи и дополнения сохраняются даже при закрытии с открытой клавиатурой:
  новая задача доступна нажатием на дисплей калькулятора, дополнение — нажатием на краткий ответ.
  Стрелка слева или «Назад» из чтения сохраняют возврат именно к краткому ответу.
  Прерванный запрос и его ошибка также сохраняются; удержание ✦ открывает состояние и кнопку повтора.
- **Фоновое выполнение** — запрос продолжает работать после «Домой», закрытия экрана и удаления
  приложения из недавних. Пока идёт вычисление, Android показывает тихое системное уведомление
  без условия задачи и ответа. Разрешение на уведомления запрашивается при первом вычислении;
  отказ не запрещает выполнение сервиса, но Android может показывать его только в списке активных приложений.
  Результат сохраняется в историю, а после запуска доступен через ✦. Фото, документ и контекст
  подготовленного запроса сохраняются приватно для ручного повтора; API-ключ в журнал не записывается.
  «Принудительно остановить», перезагрузка устройства или остановка процесса системой обрывают
  сетевое соединение: после запуска показывается «Прервано». Автоматического повторного платного
  запроса нет. Если ответ уже получен и записан локально, приложение завершает его сохранение без
  повторной отправки. Для нового запроса или выбора записи из истории предыдущее вычисление отменяется.
- **Счёт во время решения** — обычная клавиша возвращает сохранённый расчёт и сразу выполняет
  своё действие. `C` при показанном помощнике только скрывает его; повторное `C` очищает расчёт.
  Ответ или ошибка приходят тихо: точка на ✦ остаётся до просмотра. Удержание ✦ возвращает
  ожидание, ответ или ошибку. В обычном калькуляторе точки на цифрах и доступ к шагам скрыты.
- **Возврат свайпом** — в настройках можно включить «Возврат к решению свайпом» (по умолчанию
  выключен). Свайп вверх по дисплею калькулятора возвращает помощника, как удержание ✦.
  Переключатель сохраняется сразу; в редакторе и при просмотре ответа жест не действует.
- **Дополнения** — нажатие на ответ на дисплее открывает строку для следующего вопроса к нему.
  ИИ получает всю цепочку (задача, ответ, прежние дополнения), а ответ на дополнение снова
  появляется на дисплее. Черновик дополнения не меняет сохранённый расчёт. ✕ над строкой
  переключает ввод на новую задачу; отправка новой задачи заменяет текущий ответ помощника.
- **Шаблоны заданий** — примеры решённых задач одного типа (условие и решение текстом, фото или
  документом) и требования к ним. Выбранный шаблон уходит ИИ вместе со следующей задачей или
  дополнением, и ответ даётся так же, как в примерах. Дополнения к задаче, решённой по шаблону,
  тоже уходят с ним. Шаблоны экспортируются и импортируются файлом: ZIP или JSON (с фото) и
  Markdown (только текст; такой файл можно написать и вручную — «# Название», «## Требования»,
  «## Пример 1», «### Условие», «### Решение»). Образцы файлов и описание `manifest.json` —
  в [`examples/`](examples).
- **Документы** — PDF (первые 4 страницы уходят картинками), DOCX и TXT (текстом), изображения.
- **Оформление** — формулы LaTeX рисуются как в учебнике, таблицы markdown — таблицами,
  графики строятся по формулам (с логарифмической шкалой и годографами), схемы — из SVG.
- **Формат решения** — свои требования к оформлению текстом и/или фото образца.
- **История** — все решения сохраняются на телефоне.

## Готовый APK

Готовые сборки публикуются в [GitHub Releases](https://github.com/godboomaster/ai_calc/releases).
Скачайте `Calculator.apk` из нужной версии и установите на телефон
(нужно разрешить установку из неизвестных источников). После первого релиза будет доступна
[прямая ссылка на последнюю версию](https://github.com/godboomaster/ai_calc/releases/latest/download/Calculator.apk).
Название приложения — «Калькулятор». Обновление поверх прежней установки сохраняет данные;
удалять приложение перед обновлением не нужно.

APK больше не отслеживаются в Git. Выпуск из отправленной в GitHub ветки `main`:
`python scripts/release.py 1.1.0`.
Сборка и подпись выполняются локально, на GitHub остаются только проверки и готовые релизы.
[Настройка локального выпуска](docs/releases.md).

## Сборка

Нужны JDK 17+ и Android SDK 35 (проще всего — Android Studio).

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # тесты
```

Путь к SDK Android Studio прописывает в `local.properties` сама; без Android Studio создайте файл
вручную: `sdk.dir=/путь/к/Android/sdk`.

## Настройка

В приложении: значок ✦ → **Настройки**.

| Поле | Что указать |
|---|---|
| Base URL | адрес OpenAI-совместимого API, по умолчанию `https://api.openai.com/v1` |
| API-ключ | ключ от этого API; хранится только на телефоне |
| Модель | например `gpt-4o-mini`; для фото и PDF нужна модель, которая понимает изображения |

Кнопка «Проверить соединение» сохраняет настройки и отправляет пробный запрос.

## Устройство проекта

```
app/src/main/java/com/smartcalc/app/
├── SolutionViewModel.kt     — запросы к ИИ, состояние решения
├── data/
│   ├── api/OpenAiClient.kt  — запрос к модели, разбор JSON-ответа, правила для формул/графиков/схем
│   ├── plot/                — разбор формул и расчёт точек графиков
│   ├── history/, format/, settings/, template/ — хранение истории, формата, настроек, шаблонов
│   └── DocumentReader.kt, ImageUtils.kt — чтение PDF/DOCX/TXT и сжатие фото
└── ui/
    ├── calculator/          — калькулятор и клавиши ИИ
    ├── math/                — формулы LaTeX и таблицы
    ├── plot/, scheme/       — графики и схемы
    └── camera/, solution/, settings/, format/, template/ — остальные экраны
```
