# Инструкции для агентов

## Выпуск релизов

- Перед подготовкой релиза прочитайте [процесс выпуска](docs/releases.md) и [правила описания изменений](docs/release-notes.md).
- Выпускайте только из опубликованного `main`. Слияние, push и публикация должны быть разрешены пользователем; уже данное разрешение повторно не запрашивайте.
- Описание релиза пишите по-русски для пользователя приложения. Список коммитов или автоматически сгенерированные GitHub notes не заменяют описание.
- Подготовьте текст до запуска публикации. Перед завершением задачи проверьте опубликованный текст, тег, APK и контрольную сумму.
- Не включайте в Git APK, локальную конфигурацию, секреты или личные файлы. Не читайте API-ключ для сборки. Сохраняйте пакет, название и сертификат подписи для совместимого обновления.
