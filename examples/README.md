# Образцы файлов шаблонов

Тестовые файлы для импорта: скачайте на телефон и откройте в SmartCalc → ✦ → «Шаблоны» →
«Импортировать из файла». Их же можно взять за основу для своих шаблонов.

| Файл | Формат | Что проверяет |
|---|---|---|
| [`example-template.zip`](example-template.zip) | ZIP | Шаблон «Устойчивость по Гурвицу»: два примера, у первого — фото решения. |
| [`example-template.json`](example-template.json) | JSON | Тот же шаблон одним файлом, фото внутри (base64) — как экспортирует приложение. |
| [`example-template-text.json`](example-template-text.json) | JSON | Шаблон без фото — такой JSON удобно писать вручную. |
| [`example-template.md`](example-template.md) | Markdown | Шаблон «Устойчивость по Гурвицу» в Markdown — только текст. |
| [`two-templates.md`](two-templates.md) | Markdown | Два шаблона в одном файле, написанные «свободно»: без «Шаблон:», требования сразу под названием, условие без «### Условие», таблица в решении. |
| [`template-zip/`](template-zip) | — | Из чего собран ZIP: [`manifest.json`](template-zip/manifest.json) и папка `images/`. |

`example-template.zip`, `example-template.json` и `example-template.md` — один и тот же шаблон
(с одинаковым id): импорт второго и третьего после первого не добавит новый шаблон, а обновит его.

## Как собрать свой ZIP

1. Скопируйте папку `template-zip`, поправьте `manifest.json`, положите фото в `images/`.
2. Выделите **вместе** `manifest.json` и папку `images` (не саму папку `template-zip`!) и сожмите:
   Mac — правый клик → «Сжать»; Windows — правый клик → «Отправить» → «Сжатая ZIP-папка».

`manifest.json` должен оказаться в корне архива — иначе импорт ответит «Это не файл шаблонов SmartCalc».

## Правила manifest.json

- `"format": "smartcalc-templates"` и `"version": 1` — ровно так.
- У шаблона обязательно `name`. Остальное — по желанию: `requirements`, `examples`, у примера —
  `condition`, `conditionImages`, `solution`, `solutionImages`.
- `id` — по желанию. С ним повторный импорт обновляет шаблон, без него каждый импорт создаёт новый.
- Фото — в `images/`, имя латиницей, цифрами и дефисом, расширение `.jpg`
  (`primer-1.jpg` подойдёт, `фото 1.png` и `img_1.jpg` — нет).
- Формулы — в `$…$` и `$$…$$`; в JSON обратный слэш удваивается: `\\Delta`, `\\frac`.
- Пределы: `manifest.json` до 2 МБ, одно фото до 15 МБ, все вместе до 100 МБ.

Markdown проще, если фото не нужны: `# Название`, `## Требования`, `## Пример 1`, `### Условие`,
`### Решение`.
