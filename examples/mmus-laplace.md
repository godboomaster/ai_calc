# ММУС 1. Преобразование Лапласа

## Задача 1

### Условие

1.1. Найти изображение единичной ступенчатой функции $f(t) = 1(t)$.

### Решение

1) Определение преобразования Лапласа:
$$F(s) = \int_0^{\infty} f(t)\,e^{-st}\,dt$$

2) Подставим $f(t) = 1$ при $t \ge 0$:
$$F(s) = \int_0^{\infty} e^{-st}\,dt = \left[-\dfrac{e^{-st}}{s}\right]_0^{\infty}$$

3) Подставим пределы:
При $\text{Re}\,s > 0$ на бесконечности $e^{-st} \to 0$, при $t = 0$ получаем $e^{0} = 1$:
$$F(s) = 0 - \left(-\dfrac{1}{s}\right) = \dfrac{1}{s}$$

Ответ: $\dfrac{1}{s}$

## Задача 2

### Условие

1.2 а) Найти изображение экспоненты $f(t) = e^{\alpha t}\cdot 1(t)$, где $\alpha$ — действительное или комплексное число.

### Решение

1) Подставим в определение:
$$F(s) = \int_0^{\infty} e^{\alpha t}e^{-st}\,dt = \int_0^{\infty} e^{-(s-\alpha)t}\,dt$$

2) Это интеграл из 1.1 с заменой $s$ на $s - \alpha$:
Он сходится при $\text{Re}\,s > \text{Re}\,\alpha$. Комплексное $\alpha$ ничего не меняет: интеграл берётся так же.
$$F(s) = \dfrac{1}{s-\alpha}$$

Ответ: $\dfrac{1}{s-\alpha}$

## Задача 3

### Условие

1.2 б) Найти изображение линейной функции $f(t) = t$.

### Решение

1) Подставим в определение:
$$F(s) = \int_0^{\infty} t\,e^{-st}\,dt$$

2) Интегрируем по частям:
$u = t$, $dv = e^{-st}dt$, тогда $du = dt$, $v = -\dfrac{e^{-st}}{s}$:
$$F(s) = \left[-\dfrac{t\,e^{-st}}{s}\right]_0^{\infty} + \dfrac{1}{s}\int_0^{\infty} e^{-st}\,dt$$

3) Считаем оба слагаемых:
Первое равно 0: экспонента убывает быстрее, чем растёт $t$. Второй интеграл — из 1.1, он равен $\dfrac{1}{s}$:
$$F(s) = 0 + \dfrac{1}{s}\cdot\dfrac{1}{s} = \dfrac{1}{s^2}$$

Ответ: $\dfrac{1}{s^2}$

## Задача 4

### Условие

1.2 в) Найти изображение степенной функции $f(t) = t^n$.

### Решение

1) Подставим в определение:
$$F_n(s) = \int_0^{\infty} t^n e^{-st}\,dt$$

2) Интегрируем по частям, как в 1.2 б:
$u = t^n$, $v = -\dfrac{e^{-st}}{s}$; внеинтегральное слагаемое равно 0:
$$F_n(s) = \dfrac{n}{s}\int_0^{\infty} t^{n-1}e^{-st}\,dt = \dfrac{n}{s}\,F_{n-1}(s)$$

3) Повторим $n$ раз:
Доходим до $F_0(s) = \dfrac{1}{s}$ (задача 1.1):
$$F_n(s) = \dfrac{n}{s}\cdot\dfrac{n-1}{s}\cdots\dfrac{1}{s}\cdot\dfrac{1}{s} = \dfrac{n!}{s^{n+1}}$$
Проверка: при $n = 1$ получается $\dfrac{1}{s^2}$, как в 1.2 б.

Ответ: $\dfrac{n!}{s^{n+1}}$

## Задача 5

### Условие

1.3 а) Найти изображение по Лапласу синуса $\sin\omega t$.

### Решение

1) Формула Эйлера:
$$\sin\omega t = \dfrac{e^{i\omega t} - e^{-i\omega t}}{2i}$$

2) Изображение каждой экспоненты:
По 1.2 а с $\alpha = i\omega$ и $\alpha = -i\omega$:
$$F(s) = \dfrac{1}{2i}\left(\dfrac{1}{s-i\omega} - \dfrac{1}{s+i\omega}\right)$$

3) Общий знаменатель:
$(s-i\omega)(s+i\omega) = s^2 + \omega^2$:
$$F(s) = \dfrac{1}{2i}\cdot\dfrac{2i\omega}{s^2+\omega^2} = \dfrac{\omega}{s^2+\omega^2}$$

Ответ: $\dfrac{\omega}{s^2+\omega^2}$

## Задача 6

### Условие

1.3 б) Найти изображение по Лапласу косинуса $\cos\omega t$.

### Решение

1) Формула Эйлера:
$$\cos\omega t = \dfrac{e^{i\omega t} + e^{-i\omega t}}{2}$$

2) Изображение каждой экспоненты:
По 1.2 а с $\alpha = i\omega$ и $\alpha = -i\omega$:
$$F(s) = \dfrac{1}{2}\left(\dfrac{1}{s-i\omega} + \dfrac{1}{s+i\omega}\right)$$

3) Общий знаменатель:
$$F(s) = \dfrac{1}{2}\cdot\dfrac{2s}{s^2+\omega^2} = \dfrac{s}{s^2+\omega^2}$$

Ответ: $\dfrac{s}{s^2+\omega^2}$

## Задача 7

### Условие

1.3 в) Найти изображение по Лапласу затухающего синуса $e^{-at}\sin\omega t$, $a > 0$.

### Решение

1) Теорема смещения (затухания):
Если $f(t) \to F(s)$, то $e^{-at}f(t) \to F(s+a)$. Это видно из определения:
$$\int_0^{\infty} e^{-at}f(t)\,e^{-st}\,dt = \int_0^{\infty} f(t)\,e^{-(s+a)t}\,dt = F(s+a)$$

2) Применим к синусу:
Берём $F(s) = \dfrac{\omega}{s^2+\omega^2}$ из 1.3 а и заменяем $s$ на $s + a$:
$$e^{-at}\sin\omega t \;\to\; \dfrac{\omega}{(s+a)^2+\omega^2}$$

Ответ: $\dfrac{\omega}{(s+a)^2+\omega^2}$

## Задача 8

### Условие

1.3 г) Найти изображение по Лапласу затухающего косинуса $e^{-at}\cos\omega t$, $a > 0$.

### Решение

1) Теорема смещения (затухания):
Если $f(t) \to F(s)$, то $e^{-at}f(t) \to F(s+a)$ — см. 1.3 в.

2) Применим к косинусу:
Берём $F(s) = \dfrac{s}{s^2+\omega^2}$ из 1.3 б и заменяем $s$ на $s + a$ — и в числителе тоже:
$$e^{-at}\cos\omega t \;\to\; \dfrac{s+a}{(s+a)^2+\omega^2}$$

Ответ: $\dfrac{s+a}{(s+a)^2+\omega^2}$

## Задача 9

### Условие

1.4 а) Найти изображение смещённого оригинала: $f(t) = (t-\tau)^2$ при $t \ge \tau$, $f(t) = 0$ при $t < \tau$.

### Решение

1) Запишем через сдвинутую ступеньку:
$$f(t) = (t-\tau)^2\cdot 1(t-\tau)$$
Это функция $g(t) = t^2$, сдвинутая вправо на $\tau$.

2) Теорема запаздывания:
$g(t-\tau)\cdot 1(t-\tau) \to e^{-s\tau}G(s)$. Доказательство — замена $u = t - \tau$:
$$\int_{\tau}^{\infty} g(t-\tau)\,e^{-st}\,dt = e^{-s\tau}\int_0^{\infty} g(u)\,e^{-su}\,du = e^{-s\tau}G(s)$$

3) Изображение $t^2$ и ответ:
По 1.2 в при $n = 2$: $G(s) = \dfrac{2!}{s^3} = \dfrac{2}{s^3}$.
$$F(s) = e^{-s\tau}\dfrac{2}{s^3}$$

Ответ: $e^{-s\tau}\dfrac{2}{s^3}$

## Задача 10

### Условие

1.4 б) Найти изображение последовательности ступенек (смещённых оригиналов) $f(t) = A[1(t) + 1(t-\tau) + 1(t-2\tau) + \dots]$.

### Решение

1) Изображение одной ступеньки:
По 1.1 и теореме запаздывания (1.4 а):
$$1(t - k\tau) \to \dfrac{e^{-ks\tau}}{s}$$

2) Складываем все ступеньки:
$$F(s) = \dfrac{A}{s}\left(1 + e^{-s\tau} + e^{-2s\tau} + \dots\right)$$

3) Сумма геометрической прогрессии:
Знаменатель прогрессии $q = e^{-s\tau}$, при $\text{Re}\,s > 0$ $|q| < 1$, поэтому $1 + q + q^2 + \dots = \dfrac{1}{1-q}$:
$$F(s) = \dfrac{A}{s(1-e^{-s\tau})}$$

Ответ: $\dfrac{A}{s(1-e^{-s\tau})}$

## Задача 11

### Условие

1.5 а) Найти изображение кусочной функции: $f(t) = at + b$ при $t < t_2$; $f(t) = at_2 + b$ при $t_2 \le t < t_3$; $f(t) = 0$ при $t \ge t_3$.

### Решение

1) Запишем $f(t)$ одной формулой через ступеньки:
В момент $t_2$ рост прекращается — вычитаем $a(t-t_2)\cdot 1(t-t_2)$. В момент $t_3$ функция обнуляется — вычитаем $(at_2+b)\cdot 1(t-t_3)$:
$$f(t) = at + b - a(t-t_2)\cdot 1(t-t_2) - (at_2+b)\cdot 1(t-t_3)$$
Проверка: при $t_2 \le t < t_3$ получаем $at + b - a(t-t_2) = at_2 + b$, при $t \ge t_3$ — ноль.

2) Изображения слагаемых:
По 1.1, 1.2 б и теореме запаздывания:
$$at \to \dfrac{a}{s^2}, \qquad b \to \dfrac{b}{s}$$
$$a(t-t_2)\cdot 1(t-t_2) \to \dfrac{a\,e^{-t_2 s}}{s^2}$$
$$(at_2+b)\cdot 1(t-t_3) \to \dfrac{(at_2+b)\,e^{-t_3 s}}{s}$$

3) Складываем и выносим $-\dfrac{1}{s}$:
$$F(s) = \dfrac{a}{s^2} + \dfrac{b}{s} - \dfrac{a\,e^{-t_2 s}}{s^2} - \dfrac{(at_2+b)\,e^{-t_3 s}}{s}$$
$$F(s) = -\dfrac{1}{s}\left[a\left(\dfrac{e^{-t_2 s}}{s} - \dfrac{1}{s} + t_2 e^{-t_3 s}\right) + b\left(e^{-t_3 s} - 1\right)\right]$$

Ответ: $-\dfrac{1}{s}\left[a\left(\dfrac{e^{-t_2 s}}{s} - \dfrac{1}{s} + t_2 e^{-t_3 s}\right) + b\left(e^{-t_3 s} - 1\right)\right]$

## Задача 12

### Условие

1.5 б) Найти изображение полуволны синуса: $f(t) = \sin\omega t$ при $0 \le t < \dfrac{\pi}{\omega}$, $f(t) = 0$ при $t \ge \dfrac{\pi}{\omega}$.

### Решение

1) Запишем через ступеньку:
Обозначим $T = \dfrac{\pi}{\omega}$:
$$f(t) = \sin\omega t - \sin\omega t\cdot 1(t-T)$$

2) Второе слагаемое — к виду со сдвигом:
Так как $\omega T = \pi$, $\sin\omega t = \sin(\omega(t-T) + \pi) = -\sin\omega(t-T)$:
$$f(t) = \sin\omega t + \sin\omega(t-T)\cdot 1(t-T)$$

3) Изображение по 1.3 а и теореме запаздывания:
$$F(s) = \dfrac{\omega}{s^2+\omega^2} + e^{-sT}\dfrac{\omega}{s^2+\omega^2} = \dfrac{\omega}{s^2+\omega^2}\left(1 + e^{-\frac{\pi}{\omega}s}\right)$$

Ответ: $\dfrac{\omega}{s^2+\omega^2}\left(1 + e^{-\frac{\pi}{\omega}s}\right)$
